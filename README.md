Personal Portfolio Website — Frontend Developer Showcase

A modern, high-performance, and fully responsive developer portfolio landing page built from scratch with semantic HTML5, modular SCSS, and JavaScript. Designed to showcase real-world projects, technical skills, and professional experience with clean UI/UX and smooth visual feedback.

🔗 **Live Demo:** [mark-chep.github.io/portfolio-website](https://mark-chep.github.io/portfolio-website/)

 🚀 Key Features

* **Responsive & Mobile-First:** Seamless layout adaptation across all screen resolutions (Desktop, Tablet, Mobile) using fluid typography and custom SCSS breakpoints.
* **Modular BEM Architecture:** Clean, maintainable, and scalable CSS structure using BEM (Block Element Modifier) methodology and Sass variables.
* **UI/UX & Interactive Elements:** Custom SVG icons, interactive dynamic cards, and custom CSS keyframe animations for polished user interaction.
* **Social Media & SEO Optimization:** Configured Open Graph (OG) meta tags and preview assets for rich link sharing across Telegram, LinkedIn, and messaging platforms.
* **Automated CI/CD Pipeline:** Integrated GitHub Actions workflow for automatic build and deployment to GitHub Pages upon pushing to the `main` branch.


🛠️ Tech Stack

**Frontend:** HTML5, SCSS (SASS), JavaScript (ES6+)
**Architecture & Styling:** BEM Methodology, CSS Custom Properties, Flexbox, Keyframes Animation
**Tooling & Workflow:** Git, GitHub,
**Deployment & CI/CD:** GitHub Actions, GitHub Pages, Open Graph Protocol
